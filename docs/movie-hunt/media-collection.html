Media Collection

Your Movie Snipe library — browse, search, add, and manage every movie Sniparr is tracking.

What is the Media Collection?

The Media Collection is your complete view of every movie Movie Snipe is monitoring. It pulls directly from your connected Radarr instance and gives you a unified place to see what you have, what's missing, and what Sniparr is actively hunting. Think of it as your movie library dashboard — not a replacement for Radarr, but a focused view built around Sniparr's search workflow.

Browsing Your Library

Movies are displayed in a poster grid. Each card shows the movie's title, year, and a status badge:

  • Downloaded — the movie is in your library at or above your quality cutoff
  • Missing — monitored but no file found yet — Sniparr will snipe this
  • Requested — added via the Requests system, awaiting a search
  • Cutoff Unmet — a file exists but it's below your quality profile cutoff — Sniparr will try to upgrade it

Switch between Grid and List view using the controls at the top right. List view is more compact and better for scanning large libraries.

Filtering and Searching

Use the filter bar to narrow down your collection:

  • All — every monitored movie
  • Missing — shows only movies with no file, so you can see exactly what Sniparr is hunting
  • Downloaded — movies that are in your library
  • Requested — movies added through the request system

The search bar filters by title in real time. You don't need to press Enter — results update as you type. Searching is local (against your loaded collection), not a new lookup against TMDB.

Multiple Radarr Instances

If you have more than one Radarr instance configured (for example, a 4K library and a 1080p library), use the instance dropdown at the top of the collection view to switch between them. Each instance has its own separate library, profiles, and hunt queue.

Movie Detail View

Click any movie poster to open the detail panel. Here you'll find:

  • Metadata — title, year, runtime, genres, overview, and TMDB/IMDb links
  • File info — resolution, codec, audio, and the full file path on disk
  • Quality profile — which profile is applied and whether the cutoff is met
  • Custom format score — hover the score to see which formats are matched and how many points each contributes
  • Download history — every grab and import attempt Radarr has on record for this movie

Action buttons in the detail panel:

  • Force Search — trigger an immediate search in Radarr outside of Sniparr's normal cycle
  • Force Upgrade — search specifically for a better quality release even if the cutoff is already met
  • Edit — change monitored status, quality profile, or minimum availability
  • Delete — remove the movie from Radarr (with the option to also delete the file from disk)

Adding Movies

To add a new movie, use the Discover / Search button at the top of the collection view. You can search by title or TMDB ID. Results show the movie's poster, year, and whether it's already in your library.

When adding a movie you'll choose:

  • Quality Profile — which resolution and format rules apply
  • Root Folder — where on disk the movie will be stored
  • Minimum Availability — when Sniparr should start searching (Announced, In Cinemas, Released)
  • Monitor — whether to actively search for it immediately

Once added, the movie appears in your collection with Missing status and Sniparr will pick it up in the next snipe cycle.

Tips

  • The Missing filter is the fastest way to audit what Sniparr should be working on — if a movie is there and isn't being found, check your indexers and quality profile first
  • If a movie shows Cutoff Unmet, Sniparr will attempt an upgrade automatically — you don't need to force it unless you want it immediately
  • Large libraries can take a few seconds to load — the collection is fetched fresh from Radarr each time so you're always seeing live data
  • Root folders and quality profiles are managed per-instance — make sure you've configured them for every Radarr instance under Settings → Movie Snipe
